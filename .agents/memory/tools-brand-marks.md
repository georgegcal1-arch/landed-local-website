---
name: Tool brand marks
description: The all-or-none requirement for third-party tool logos on Landed Local.
---
Use official, clean, single-color tool marks only when a complete set is available for all six configured tools. Otherwise keep every tool text-only; do not approximate or mix logos and text-only names.

**Why:** The user explicitly requested a complete set or none, with unavailable marks identified in the completion report.

**How to apply:** Recheck official sources before introducing any logos. Availability in an icon library alone does not establish availability for the complete set.
