---
name: Tools motion exception
description: The tools strip is the explicit exception to the site's once-only animation rule.
---
The user explicitly requested a continuous tools loop with pause/play, hover pause, and a static reduced-motion list. All other site animation remains once-only.

**Why:** The design-fix brief specifically restores scrolling tool names despite the general once-only rule in the project instructions.

**How to apply:** Preserve continuous movement only for the tools strip, along with its controls and accessible reduced-motion output. Do not extend this exception to hero, drafting marks, checks, or other content.
